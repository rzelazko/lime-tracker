# Security Policy

## Supported Versions

The following versions of Lime Tracker are
currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's **private vulnerability reporting** instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form (summary, details, proof of concept, impact).

Your report is delivered privately to the maintainers as a security advisory, where we can discuss the issue, coordinate a fix, and credit you if you wish.

If the "Report a vulnerability" button is not available, contact the maintainer through GitHub to arrange a secure channel — **without including any vulnerability details in public channels**.

By responsible disclosure we mean: you give us a reasonable opportunity to investigate and release a fix before any public disclosure, and you avoid accessing other users' data, degrading service availability, or otherwise causing harm while validating a report.
